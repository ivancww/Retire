# Retire

Independent AVA retirement-planning conversation app. Current app version: **0.1.0**.

The app is local-first, keeps customer inputs on-device, and reads official defaults/return plans from the Retire-owned GAS endpoint. It does not depend on 5pay at runtime.

Run locally with any static server, for example `python3 -m http.server 8080`, then open `http://localhost:8080/`. Run unit tests with `npm test`.
